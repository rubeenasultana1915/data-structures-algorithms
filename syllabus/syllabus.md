# Syllabus of CS 2XX

# Data Structures and Algorithms

## 1 Overview

### 1.1 Description

This course introduces fundamental data structures and algorithms used in computer science. Topics include algorithm analysis, arrays, linked lists, stacks, queues, recursion, searching, sorting, hashing, trees, heaps, graphs, shortest-path algorithms, minimum spanning trees, greedy algorithms, dynamic programming, and backtracking.

The course emphasizes both theoretical analysis and practical implementation. Students will design, implement, analyze, and evaluate algorithms using C++.

Students who miss an assessment should contact the instructor as soon as possible regarding the applicable university/course policies.

### 1.6 Topical Outline

The main topics include:

* Algorithm analysis and asymptotic notation
* Arrays and vectors
* Searching
* Linked lists
* Stacks, queues, and deques
* Recursion and recurrence relations
* Sorting algorithms
* Divide-and-conquer
* Hash tables
* Binary trees and binary search trees
* Heaps and priority queues
* Graph representations
* BFS and DFS
* Shortest-path algorithms
* Minimum spanning trees
* Greedy algorithms
* Dynamic programming
* Backtracking
* Algorithm selection and performance analysis

### 1.7 Student Learning Outcomes

At the completion of this course, students will be able to:

* Analyze algorithms using Big-O, Big-Ω, and Big-Θ notation.
* Implement fundamental data structures in C++.
* Implement and analyze searching and sorting algorithms.
* Select appropriate data structures and algorithms for computational problems.
* Apply recursion, divide-and-conquer, greedy, dynamic-programming, and backtracking techniques.
* Implement and analyze fundamental graph algorithms.
* Compare theoretical complexity with empirical performance.
* Explain algorithmic solutions using clear reasoning, pseudocode, code, and complexity analysis.

Generative AI tools such as ChatGPT and GitHub Copilot may be used only in ways explicitly permitted by the instructor or individual assignment.

Unless an assignment states otherwise:

* Students may use AI to clarify general concepts or explain errors.
* Students remain responsible for the accuracy and originality of submitted work.
* Students may not submit AI-generated solutions as their own work.
* Students must be able to explain the algorithms and C++ code they submit.
* Assignment-specific AI requirements will be stated in the assignment instructions.

Unauthorized AI assistance may be treated as unauthorized assistance under the university's academic integrity policies.
