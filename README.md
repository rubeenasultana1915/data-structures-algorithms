# Data Structures and Algorithms

University-level Data Structures and Algorithms course materials designed for undergraduate Computer Science students.

## Course Overview

This course introduces fundamental data structures and algorithms used in computer science. Students learn to design, implement, analyze, and evaluate algorithms using appropriate data structures.

## Course Format

- Level: Undergraduate
- Credits: 3
- Duration: 15 weeks
- Programming Language: C++17
- Lectures: 2 × 75 minutes per week
- Laboratory: 1 × 75 minutes per week

## Topics

- Algorithm analysis
- Big-O, Big-Theta, and Big-Omega
- Arrays and vectors
- Searching
- Linked lists
- Stacks and queues
- Recursion
- Sorting
- Divide and conquer
- Hash tables
- Binary trees and BSTs
- Heaps and priority queues
- Graphs
- BFS and DFS
- Shortest-path algorithms
- Minimum spanning trees
- Greedy algorithms
- Dynamic programming
- Backtracking

## Learning Philosophy

Students are expected to:

1. Understand fundamental data structures and algorithms.
2. Implement algorithms correctly in C++.
3. Analyze time and space complexity.
4. Select appropriate algorithms and data structures for problems.
5. Compare theoretical and empirical performance.
6. Communicate algorithmic reasoning clearly.
